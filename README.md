## 🤔 为什么会有这个项目？

事情是这样的——

某天，女朋友又双叒叕说：**「好无聊啊～～」** 😮‍💨

作为一个有求必应（且求生欲极强）的男朋友，我陷入了沉思：

- 🎬 看电影？看过了。
- 🍜 吃东西？刚吃过。
- 🚶 出门？外面太热/太冷/太远。
- 💬 聊天？聊到没话题了。

于是，**「甜蜜星球」** 诞生了！一个专门为「女朋友无聊应急」而生的网页游乐场，打开浏览器就能玩，6 个小游戏打包送上，专治各种「无事可做」。

> ✨ **项目核心目的**：用代码消灭女朋友的无聊时光，让她在屏幕前咯咯笑出声，从而守护世界和平（划掉），守护恋爱安宁。

## 🎨 技术栈

纯手写，零依赖，打开即玩：

- **HTML5** — 单文件结构，所有代码都在一个 `index.html` 里
- **CSS3** — 玻璃拟态（Glassmorphism）+ 渐变动画 + 响应式布局
- **原生 JavaScript** — 无任何框架，无 jQuery，无构建工具
- **Canvas API** — 飘落的心形 & 花瓣粒子特效背景
- **Google Fonts** — `Ma Shan Zheng` + `ZCOOL KuaiLe` 中文可爱字体

> 一个 `index.html` 走天下，复制到任何地方都能跑。

## 📦 本地运行

想本地看看？三种方式任选其一：

### 方式一：直接双击（最简单）
```powershell
# PowerShell 中直接用默认程序打开
start index.html
```

```cmd
:: CMD 中
start index.html
```

### 方式二：起个本地服务器（推荐，避免某些浏览器限制）
```powershell
# Python 3
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000
```

### 方式三：用 VS Code Live Server 插件
右键 `index.html` → `Open with Live Server`，搞定。

## 🚀 部署方式（GitHub Pages）

本项目已通过 GitHub Pages 部署，公网可访问。如果你也想自己部署一份：

1. **Fork 本仓库**（或上传 `index.html` 到自己的 GitHub 仓库）
2. 进入仓库 **Settings** → **Pages**
3. **Source** 选择 `Deploy from a branch`
4. **Branch** 选择 `main` / `(root)` → **Save**
5. 等 1~2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

完事。零成本、零服务器、零运维。
